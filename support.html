Scroll in Peace desktop testing

Testing Scroll in Peace in Chrome, Edge, or Firefox on your computer? Download the kit below. It includes the extensions and installation instructions.

Download desktop tester kit (ZIP)

Extract the ZIP, then open TesterNotes.md and follow the instructions for your browser. Chrome and Edge testers receive version 1.0.2; Firefox desktop testers receive version 1.0.1 and need Firefox 153 or newer.

Firefox testers: extract the kit, open about:addons → Extensions → gear menu → Install Add-on From File, and choose the signed .xpi in the Firefox folder. If you previously loaded a temporary add-on, quit and reopen Firefox first. Extension upgrades are manual during this beta; filter updates are automatic.

Chrome/Edge 1.0.2 and Firefox 1.0.1 receive Scroll-maintained site fixes through filter updates. Existing Firefox testers should install the newer signed XPI; Chrome/Edge testers should update and reload their existing unpacked folder. Approve the new support-site download permission if requested. Safari does not use the site-fixes list yet.

Firefox upgrade check: in about:addons → Scroll in Peace → Permissions and data, make sure access to https://easylist.to and https://jocular-sherbet-13dd23.netlify.app is on. Firefox may leave the new support-site switch off after an upgrade. Enable it, click Update filters, and confirm the Scroll site fixes version in Filter details & settings. No Firefox account sign-in is needed.

This is a test build. Firefox includes a Mozilla-signed add-on that stays installed after restarting the browser; its network blocking coverage is smaller than the Chrome/Edge edition. Safari testers should use their separately supplied app or TestFlight build. The kit is for desktop browsers.

Scroll in Peace setup

On iPhone, iPad, and Mac, Scroll in Peace's App Store app provides Safari protection. Enable Scroll in Peace Filters (Ads & Cleanup) and Scroll in Peace Privacy in Safari Settings. Enable Advanced Protection and its YouTube access separately if you want supported Skip Ad controls.

Desktop Chrome, Edge, and Firefox require the separate Scroll in Peace browser extension. Installing the Safari app does not install or activate those extensions. This release does not provide Scroll in Peace blocking inside Chrome, Edge, or Firefox on iPhone or iPad. Firefox desktop requires version 153 or newer.

After installing a desktop extension, wait for the maintained filter update to finish. Allow optional page cleanup or YouTube access if desired, then reload already-open pages. Advanced Protection starts off and activates only available recognized Skip Ad controls. Browser rule budgets and unsupported filter syntax limit coverage; some ads can remain.

For a stuck or failed update, send the displayed error and your app/browser versions. Avoid reinstalling or deleting your settings before contacting support.
