Review a reported site, validate a targeted rule, then publish the updated fixes through your Netlify account.

Edits stay in this browser tab until you download them. This page cannot change the live list or anyone’s extension. Reports and pasted page markup are never uploaded.

1. Check the report

Ask for the site address, browser/version, extension version, a redacted screenshot, and whether page cleanup is allowed. Confirm the report yourself. In browser developer tools, use Network to identify the ad provider, or inspect an empty ad container to find a specific CSS selector.

Rule examples and limits

||ads.example.com^$domain=news.example.com
news.example.com##.advertisement-placeholder

! Undo a matching cleanup rule for a site:
news.example.com#@#.advertisement-placeholder

! Allow a provider request mistakenly blocked on this site:
@@||media.example.com^$domain=news.example.com

Every rule must name the affected website. Supported: anchored hostname network rules, standard CSS hiding rules, and their exceptions. No JavaScript, scriptlets, redirects, raw regex, badfilter, or whole-page document rules. Maximum 200 network and 200 cleanup rules.

A valid rule is not proof of a correct fix. Check articles, sign-in, video/camera playback, scrolling, and consent controls before publishing. Never use a broad selector such as body to remove an advertisement.

  1. Open your existing jocular-sherbet-13dd23 project in Netlify.
  2. Under Production deploys, choose browse files to upload and upload the complete downloaded ZIP. Uploading only the fixes file would remove the other website files from the new deployment.
  3. Wait for Published, then reopen this page and click Load published list. Confirm the new version and rules.
  4. Ask a tester with the fixes-enabled extension to click Update filters, then reload the affected page. Confirm the Scroll site fixes version in Filter details & settings.

Automatic filter checks pick up changes within about six hours while the browser is running. A sleeping browser or failed download can delay this; Update filters retries immediately.

If a fix breaks a site, remove that rule and publish a new version, or restore the previous full website deployment in Netlify. Testers can also use Restore previous filters for immediate local rollback.

The first fixes-enabled versions are Chrome/Edge 1.0.2 and Firefox 1.0.1. Older editions do not download this list. Install the Mozilla-signed Firefox 1.0.1 package from the tester kit before it can receive fixes. Safari does not use this list yet.
